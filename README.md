# RUQAYA Portfolio

Faithful reconstruction of [ruqaya.ai.studio](https://ruqaya.ai.studio/) — Leadership in Circular Economy & Waste Management.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide React
- Framer Motion (available; interactions use CSS transitions matching the reference)

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (default `http://127.0.0.1:5173/`).

## Build

```bash
npm run build
npm run preview
```

## Features

- Full homepage sections: Hero, Service Tracks, Expert Profile, Projects (filterable), Resources (search + filters + model expand), Contact form
- Courses / Training page (`#courses`) with flyer, schedules, and reservation form
- EN / ES language switch
- Sticky nav, smooth scroll, WhatsApp / email / LinkedIn links
- Contact & course forms: client-side validation; submit opens `mailto:` (no backend)
